
## 배경

컴퓨터 비전 분야와 자연어 처리 분야에서 초대규모 데이터를 학습한 backbone을 두고 여기에 정제된 데이터를 학습 시켜 파인튜닝하는 방식은 매우 성공적인 성과를 거두고 있다. 이러한 아이디어에서 착안하여 해당 연구는 대규모 로봇 데이터(심지어는 로봇 데이터가 아닌 것까지도)를 학습한 robot foundation model을 만들고자 한다.

또한 로봇의 경우 실수 상황을 극복하는 방법도 학습해야 한다. 하지만 고품질의 데이터만으로 학습하면 실수 상황을 배울 수 없고 저품질의 데이터만으로 학습하면 모델이 제대로 동작하기 힘들다. 따라서 저-고품질 데이터를 모두 학습해야 한다.

이전 VLA 연구들은 VLM이 autoregressive하게 discrete action token을 생성했다. 하지만 본 연구는 flow matching을 도입해 모델이 continuous action chunk를 생성할 수 있도록 했다. 토큰을 생성하는 기존의 아이디어는 VLM 백본과는 잘 맞지만 로봇 동작은 discrete하지 않고 continuous하기에 이에 맞춘 변화이다.

## 아이디어

Transfusion에서 영감을 받아 이산적인 텍스트 토큰은 cross-entropy로 학습하고 action 같은 연속적인 토큰은 flow matching으로 학습한다. 

이미지, 상태는 각각의 인코더를 통과한 뒤 선형 레이어에서 언어 토큰과 같은 차원으로 변환된다.

모델은 10 스텝의 오일러 근사를 활용하는데 10 스텝의 반복 연산 과정에서 observation은 바뀌지 않는다. 따라서 observation(prefix) token들은 kv caching하여 사용한다. 

Full bidirectional attention을 통해 action token끼리는 순서에 관계없이 서로를 볼 수 있다. Causal masking이라면 50번째 행동 토큰이 1번째 행동 토큰을 볼 수 없지만 full bidirectional attention이라면 볼 수 있다. 행동 궤적은 시간적 연관성이 강해 뒤쪽 행동까지 고려하여 앞의 행동을 결정하는 것이 자연스럽다.

다양한 환경, 로봇 종류, task 데이터를 모아 하나의 versatile한 모델을 학습하다 보니 입력 데이터의 차원이 제각각이다. 해당 연구는 모든 데이터를 수용할 수 있도록 가장 크게 차원을 만들고 몇몇 차원을 사용하지 않는 데이터가 입력되는 경우 제로 패딩으로 처리했다.

## 결과

![[Pasted image 20260505234920.png]]
Pretrained VLM을 backbone으로 갖는 경우($\pi_0$)가 from scratch 모델($\pi_0-small$)보다 언어 지시 이행에 더 나은 성능을 보였다. 하지만 $\pi_0-small$은 0.4B 파라미터이기에 모델 크기 차이에서 오는 성능 하락 또한 고려해야 한다.

![[Pasted image 20260505235206.png]]
사전학습을 진행한 모델과 바로 downstream task로 진입한 모델을 비교하면 사전학습을 진행한 쪽이 더 나은 성능을 보이는 것처럼 보인다. 사전학습에서 downstream task와 유사한 행동을 학습한 경우에는 유의미한 차이를 보였지만 그렇지 않은 경우에는 큰 차이를 보이지 않았다.

![[Pasted image 20260505235425.png]]
이번 task들은 5~20분 길이의 complex multi stage task들이다. OpenVLA, Diffusion policy와 같은 외부 baseline들은 해당 task들을 해결하지 못해 해당 연구의 모델들끼리만 비교한다. 전반적으로 사전학습과 파인튜닝을 모두 거친 모델이 가장 좋은 성능을 보인다. 사전학습만 한 모델의 경우 사전학습에서 봤던 것과 비슷하지만 더 복잡한 문제를 푸는 데 어느정도는 성공했지만 사전학습에서 보지 못한 복잡한 작업은 전혀 수행하지 못했다.
